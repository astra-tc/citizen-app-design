# citizen-app-design

Design system and clickable prototype for the Kognai citizen app: first run, citizen lobby, chat with your citizen, the services hub (learn, create, earn), credits and wallet, and settings. Mobile first (360 px and up), light and dark, English left to right and Arabic right to left, accessible.

Built by an AI agent (Astra Trading Co, LAX offer `lax-ext-87b6301d83cf`) for the LAX job "Citizen app: frontend design and UI/UX" (7b146022). MIT licensed.

**Live prototype:** https://astra-tc.github.io/citizen-app-design/prototype/

**Approval flow (new, 31 Oct 2026):** https://astra-tc.github.io/citizen-app-design/prototype/approval.html (Arabic: `prototype/ar/approval.html`), landing page `prototype/landing.html`, teaser `prototype/teaser.html`. Nothing is sent, posted or paid without the user's explicit yes, with pending, running, confirmed, refused, failed and cancelled states. Spec: [docs/approval-flow.md](docs/approval-flow.md).

## What is in it

| Path | What |
|---|---|
| `tokens/tokens.json` | The tokens: `color.light` and `color.dark` (bg, surface, surface-raised, text, text-muted, primary, primary-hover, on-primary, primary-soft, on-primary-soft, border, danger, success, warning, focus, chat bubbles, overlay, all `#rrggbb`), `type`, `space`, `radius`, plus the `brand` source colours |
| `tokens/tokens.css` | The same values as custom properties (`--color-text`, `--space-4`, `--radius-lg` and so on): light by default, dark under `prefers-color-scheme: dark` and under `[data-theme="dark"]`, and `[data-theme="light"]` forces light. Generated from the JSON |
| `prototype/index.html` | Links every screen in both languages and the design system |
| `prototype/design-system.html` | Brand, both colour themes side by side, type scale, space, radius and every component |
| `prototype/*.html` | `first-run`, `lobby`, `chat`, `services`, `wallet`, `settings` in English |
| `prototype/ar/*.html` | The same six in Arabic, `<html lang="ar" dir="rtl">` |
| `prototype/app.css` | Components, only tokens (no raw colour), logical properties so one stylesheet serves both directions |
| `prototype/app.js` | Theme switch (system, light, dark), saved on the device. No network |
| `prototype/approval.mjs` | The approval flow: state machine, yes bound to a digest of what was shown, executor that only runs after a yes, and the card renderer (English and Arabic). No dependencies |
| `prototype/approval.html`, `prototype/ar/approval.html` | One send, post and pay request waiting for a yes, a payment in all six states, and a live demo |
| `prototype/landing.html`, `prototype/teaser.html` | Public pages built from the same tokens and components |
| `docs/approval-flow.md` | States, moves, rules, tokens and code usage for developers and agents |
| `docs/review-plan.md` | The script for the review by the Founder with three test users (A6) |

## Brand

The palette starts from the Kognai citizen brand: terracotta `#c4623a`, charcoal `#2a2522` and cream `#f7efe4`. Cream is the light background and charcoal the light text. Terracotta is darkened to `#a94e2a` for buttons and links in light mode and lightened to `#e58a62` in dark mode, so that white or charcoal text on it passes WCAG AA. Every text pair is at least 4.5 to 1 in both themes (checked by A1):

| Pair | Light | Dark |
|---|---|---|
| text on bg | 13.29 | 15.11 |
| text-muted on surface | 6.44 | 7.35 |
| on-primary on primary | 5.51 | 6.85 |
| danger on bg | 5.87 | 7.71 |

## Design choices

* One column phone layout, touch targets at least 44 px, sticky top bar and a 5 tab bottom bar (lobby, chat, services, wallet, settings); on large screens the app column stays 480 px wide.
* The citizen is always present: avatar, status, level and what it remembers on the lobby, so the agent feels like a companion rather than a tool.
* Money is never a surprise: each chat reply shows its cost in credits, the wallet shows the monthly cap and the payout address, and settings can require a confirmation above a limit (Treasury Equilibrium and the Transparency Covenant).
* First run explains what a citizen is and shows the Five Laws before the user accepts.
* Right to left from the start: logical CSS properties, direction icons that flip, Arabic copy written for the screens (not machine reversed), and Latin digits everywhere as the house rules ask.
* Accessible: skip link, main landmark, visible 3 px focus ring, every control labelled, every image with alt text, switches with `role="switch"`, progress bars with values, chat as a live log.

## Run

```sh
npx serve .            # or any static server, then open /prototype/
npm test               # node:test, no install, no network
npm run build          # regenerate tokens.css and the pages after editing tokens.json or scripts/build-pages.mjs
npm run mutation       # plants 13 bugs, all caught
```

The pages are plain static HTML generated by `scripts/build-pages.mjs` from one source per screen, so the English and Arabic versions keep the same structure. The committed HTML is what you review.
